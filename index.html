YouTube-avain ja asetukset

Peli etsii jokaiselle biisille videon YouTubesta. Siihen tarvitaan ilmainen YouTube Data API -avain. Avain tallentuu vain tähän selaimeen.

Omat YouTube-soittolistat

Soita biisejä omalta YouTube- tai YouTube Music -soittolistaltasi. Tähän ei tarvita avainta.

  1. Tee soittolista YouTubessa tai YouTube Musicissa.
  2. Aseta näkyvyydeksi Julkinen tai Listaamaton. Yksityisiä listoja peli ei pysty soittamaan.
  3. Valitse listalla Jaa → Kopioi linkki ja liitä se alle.

Vastauksena näytetään videon nimi ja kanava YouTubesta. Peli lukee listalta enintään noin 200 ensimmäistä biisiä.

Omat tekstilistat

Liitä lista, yksi biisi per rivi muodossa Bändi - Biisi - Vuosi. Vuosi on vapaaehtoinen. Pyydä Claudelta uusi genre tässä muodossa ja liitä se tähän.

YouTube-avaimen käyttöönotto
  1. Avaa console.cloud.google.com ja luo uusi projekti.
  2. Valitse APIs & Services → Library, hae YouTube Data API v3 ja paina Enable.
  3. Valitse Credentials → Create credentials → API key.
  4. Avaa luotu avain ja rajaa se:
    • Application restrictions → Websites → lisää tämän sivun osoite
    • API restrictions → Restrict key → valitse vain YouTube Data API v3
    Paina Save. Rajaus voi tulla voimaan vasta noin 5 minuutin päästä.
  5. Kopioi avain ja liitä se yllä olevaan kenttään. Avain tallentuu vain tähän selaimeen.

Avain on ilmainen, eikä siitä tule laskua. Se riittää noin 100 biisihakuun päivässä, ja löydetyt biisit muistetaan. Kirjaudu YouTubeen samassa selaimessa, niin Premium pitää mainokset poissa.
